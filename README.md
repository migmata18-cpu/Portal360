# Portal360

Aplicación web para digitalizar y centralizar la gestión de Recursos Humanos.

Proyecto final de IA Aplicada en Relaciones Industriales, UCAB.

## Módulos

- Permisos y vacaciones
- Inducción (Onboarding)
- Histórico de incidencias

## Tecnologías

React, Vite, TypeScript, Supabase y Netlify. Desarrollado con Claude Code.

## Estado

En desarrollo. Todos los datos utilizados son ficticios.
